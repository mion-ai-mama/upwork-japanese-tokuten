## 3. 差別化（競合特典との比較）

競合（note記事。レストラン電話予約＋AIへの頼み方3種）は、登録・プロフィール、提案文、手数料やConnectsの数字、税金、規約・責任の説明が薄い。この特典は、始める前の確認（手数料・本人確認・出金・ルール）、募集文の読み解き、応募メッセージ、電話予約の準備、受け取りと税金まで通す。競合の文章・プロンプトは転載していない（プロンプトは自作）。

## 4. 公式確認（2026-11-18）

- 手数料: 契約ごとに0〜15%（応募時に表示）／出金: 米国外の銀行へ1回0.99USD（受取銀行の手数料は別）、4営業日以内、最低5USD／Connects: 1つ0.15USD・必要数は募集ごと／本人確認: 写真つきID・期限内に完了／時給は週の請求から約10日後、固定は承認5日後に出金可
- 規約: 契約前の連絡先交換禁止、支払いはUpwork内、複数アカウント・共有・他人名義の禁止
- 日本は利用可能国、Direct to Local Bank対応国に含まれる
- 国税庁 No.1906: 給与以外の所得が20万円超で原則確定申告（海外報酬の扱いは未確認→税務署案内）
- 実際の募集例: Upworkの公開検索（2026-11-18）。個人名・会社名なし
