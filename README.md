# みおん式AI副業ノート 海外の日本語のお仕事編

日本語を使って海外の依頼を受けるお仕事（Upwork）の探し方と、英語のやりとりをChatGPTに手伝ってもらうプロンプトを解説する特典ページ（Instagramリール用）。v2テンプレート（白×黒×グレージュ）の複製。

## 編集
- 文章・画像・動画・LINEリンク: `js/content.js` のみ
- 色・フォント・余白: `css/style.css` の `:root`
- LINE誘導: `js/content.js` の `lineIntro`（つなぎ）だけ。ストーリー〜CTAは `js/line-cta.js` の共通文章
- 解説動画: 未撮影（`hero.tutorial`）。撮影台本は `撮影台本/海外の日本語のお仕事編_解説動画_撮影台本.md`

## ローカル確認
`python3 -m http.server <port>`
